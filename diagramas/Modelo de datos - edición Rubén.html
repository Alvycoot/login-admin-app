Protocolos de seguridad防御プロトコル

  • R-01
    Luz y gas no se mezclan

    Un suministro de gas no puede llevar potencia, ni uno de luz tipo de instalación.

    CHECK
  • R-02
    Un suministro de cada tipo

    Un activo no puede tener dos suministros de luz ni dos de gas.

    UNIQUE (activo_id, tipo)
  • R-03
    Identificadores sin duplicados

    El CUPS, el CIF, la referencia catastral y el código del activo no se repiten.

    UNIQUE
  • R-04
    Cada uno en su sección

    Un usuario solo lee y escribe en las secciones que tiene asignadas. LECTOR nunca escribe.

    ROW LEVEL SECURITY
  • R-05
    Registro que no se toca

    Al registro de actividad solo se le añaden filas: nadie las modifica ni las borra, y solo ADMIN lo lee.

    SOLO AÑADIR
  • R-06
    Hasta las consultas dejan huella

    Búsquedas y consultas pasan por funciones que las apuntan. Un intento sin permiso queda como ACCESO_DENEGADO.

    FUNCIONES + DISPARADORES
