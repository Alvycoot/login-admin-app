# login-admin-app

Aplicación web con login, base de datos y panel de administrador, construida como proyecto de aprendizaje y presentación técnica.

Temática: activos inmobiliarios ficticios (fondos, activos, suministros). Datos inventados.

## Diagramas
En `diagramas/` hay tres versiones del modelo de datos (formal y dos variantes de estilo), solo para consulta visual — no forman parte de la aplicación.
